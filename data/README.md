## Raw inputs used for simulation regeneration

The simulation-regeneration workflow starts from three public GSE130711 indexed-contact files under `data/raw/simulation/Raw_Data/`. These raw files are available from GEO and are not distributed in this repository. Users who do not need to regenerate the simulation inputs from raw contacts can start from the processed simulation archive instead.

Expected raw file names:

- `GSM3749700_190305_snm3Cseq_hs_29yr_BA10_UMB5580_1_UMB5580_2_A11_AD004_indexed_contacts.txt`
- `GSM3750251_190315_snm3Cseq_hs_21yr_BA10_UMB5577_3_UMB5577_4_A9_AD010_indexed_contacts.txt`
- `GSM3751478_190315_snm3Cseq_hs_29yr_BA10_UMB5580_3_UMB5580_4_C10_AD006_indexed_contacts.txt`

| Study | Expected path | Contents |
| --- | --- | --- |
| Simulation | `data/processed/simulation/input/` | Processed simulation RData files with `true_muS`; filenames use `Simulation_snm3Cseq_human_brain_astrocytes_50k_chr*.RData`. |

| NPC chrX recovery | `data/processed/NPC_chrX/list_muS_unified_260614.RData` | Combined manuscript-scale matrix object for Raw, HiCBZIP-GB/GB(NB), HiCBZIP-N(M), HiCImpute, scHiCluster, Higashi, and Fast-Higashi across the NPC chrX downsampling levels. |

Large `.scool`, `.RData`, `.mat`, and raw contact files are excluded from the GitHub repository. The GitHub repository provides code, documentation, small test data, and expected input paths; large processed data are provided through cited public sources or external archives.

`results/simulation/manuscript_summaries/muS_combined_plot_260209.RData` is generated by `simulation/summarize_simulation_metrics.Rmd` and is not required as an archived input.
