## Raw inputs used for simulation regeneration

The optional simulation-regeneration workflow expects three GSE130711 source indexed-contact files under `data/raw/simulation/Raw_Data/`. These files are large and should not be committed to GitHub unless Git LFS is used. The public workflow can instead start from archived processed simulation inputs.

Expected raw file names:

- `GSM3749700_190305_snm3Cseq_hs_29yr_BA10_UMB5580_1_UMB5580_2_A11_AD004_indexed_contacts.txt`
- `GSM3750251_190315_snm3Cseq_hs_21yr_BA10_UMB5577_3_UMB5577_4_A9_AD010_indexed_contacts.txt`
- `GSM3751478_190315_snm3Cseq_hs_29yr_BA10_UMB5580_3_UMB5580_4_C10_AD006_indexed_contacts.txt`

Do not commit large `.scool`, `.RData`, `.mat`, or raw pair archives to GitHub unless they are intentionally tracked with Git LFS. For journal submission, place large processed inputs and final non-code reproducibility files in a versioned archive and cite its DOI in the manuscript data-availability statement.

`results/simulation/manuscript_summaries/muS_combined_plot_260209.RData` is generated by `simulation/summarize_simulation_metrics.Rmd` and is not required as an archived input.
